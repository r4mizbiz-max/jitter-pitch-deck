# Ad videos

Drop your ad clips in this folder with these **exact filenames** and they'll auto-play
when you click the matching button on the "actual ads" slide:

| Button on deck   | Filename                     |
|------------------|------------------------------|
| Price Anchor     | `ads/price-anchor.mp4`       |
| Problem Aware    | `ads/problem-aware.mp4`      |
| Problem Unaware  | `ads/problem-unaware.mp4`    |
| Solution Aware   | `ads/solution-aware.mp4`     |
| Social Proof     | `ads/social-proof.mp4`       |
| Offer / Direct   | `ads/offer-direct.mp4`       |

Until a file is added, clicking the button shows a placeholder telling you which file to drop in.
`.mp4` (H.264) plays everywhere. Commit the files and push — GitHub Pages serves them automatically.
